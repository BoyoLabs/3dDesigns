# 3D prints

This folder and subsequent README file is to document prints I've done *not designed by me.* I intend on giving the link location to where the design can be found and explain both the why I made it, and the process I took to make it. I will talk about the printer I used, the slicer and slicer settings I used, the filament, and the results (i.e. whether it failed, how it failed, what I did to get it working, and what happened.)

*This folder/readme is moreso for me to catalogue the work I've done, the most that it will ever give back to the community is a possible source of fixes for the niche set of files I have printed*
